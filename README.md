# Courtly — ЛР-7

Адаптивна landing page сервісу бронювання спортивних майданчиків за [макетом викладача](https://denysmatsevych.github.io/web-development-2026/labs/lab-7/task/).

## Локальний запуск у VS Code

Відкрийте цю папку через **File → Open Folder**, потім **Terminal → New Terminal**:

```powershell
npm.cmd start
```

Відкрийте http://127.0.0.1:4177/. Для зупинки сервера натисніть Ctrl+C. Встановлювати npm-пакети не потрібно.

## Файли

- `index.html` — семантичні секції, форма, картки, метадані SEO.
- `tokens.css` — незмінені токени з архіву викладача.
- `styles.css` — mobile-first CSS, Grid, Flexbox, фокус, адаптивність.
- `menu.js` — тільки мобільне меню: Enter/Space, Escape, aria-expanded.
- `img/` — зображення викладача; `fonts/` — локальний Montserrat 400–800 з кирилицею та ліцензією OFL.
- `robots.txt`, `sitemap.xml` — індексація сторінки.
- `scripts/serve.cjs` — локальний сервер Node.js, не браузерний код.

## Поведінка за умовою

Форма демонстраційна: нативна валідація `required`, після відправлення перехід до `#venues`. Вибір «Будь-який» має порожнє значення, тому обов’язкове поле вимагає вибрати спорт — саме так вказано в завданні. Кнопки бронювання не виконують реальних дій. Контакти взято з макета; соціальні посилання ведуть на головні сторінки сервісів, оскільки профілі Courtly не надані.

Картки: 1 колонка, з 640px — 2, з 1024px — 3. Arena Sport на desktop займає 2×2 комірки. Інформаційна секція має окремий breakpoint 768px згідно зі специфікацією. Значення `clamp()` уже визначені в токенах.
